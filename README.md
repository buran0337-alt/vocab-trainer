# CET-6 Vocabulary Trainer

个人使用的英语六级单词记忆 Web 应用。阶段 1–12 的实现和质量验收已完成，首期版本已具备交付条件，等待用户最终确认。

## 当前范围

- 首页、学习、薄弱、检验、单词库、分组、统计和设置八个入口。
- 单词库支持手动添加、编辑、查看详情、删除及英文/中文即时搜索。
- 支持导入 `.xlsx`、`.xls` 和 `.csv`。
- Excel 可选择多个工作表，并逐个工作表确认列映射。
- 导入预览区分新增、已有相同、释义冲突、文件内重复、无效和空行。
- 重复单词会复用原记录；释义冲突可选择保留原释义或更新释义。
- 长单词和中文释义可换行显示，移动端使用单列布局。
- 尚未完成的页面使用清晰空状态，不使用虚构学习数据。
- TypeScript 类型检查、ESLint、Vitest 单元测试和生产构建配置。
- IndexedDB 数据模型、数据访问仓库、北京时间转换和事务测试。
- 学习页面支持英译中、中译英、显示答案和三档反馈；反馈会原子保存。
- 首页显示每日目标、动态有效任务、完成量、剩余量和到期复习。
- 设置页可保存 0–999 的每日新词目标，修改后立即生效。
- 统计页显示学习概览、7/30 天与全部历史趋势、反馈比例、薄弱词变化和分组数据。
- 分组页支持创建、重命名、删除和成员管理。
- 进入分组后同时浏览组内单词，点击可独立展开/收起完整释义。
- 新增独立“检验”入口，可按全部词库或分组批量浏览、搜索和展开释义。
- 新增独立“薄弱”入口，按全部历史计算薄弱分并复用共享复习反馈。
- 统计页显示真实薄弱词数量。
- 设置页支持下载完整 JSON 备份，并通过校验和二次确认执行完整覆盖恢复。

## 环境要求

- Windows 10 或 Windows 11。
- Node.js 22.22.2、24.15 或更新的受支持版本；推荐使用当前 Node.js 24 LTS。本项目已在 Node.js 24.22.1 上检查。
- npm 10 或更高版本。

## 第一次使用

在项目目录打开 PowerShell，然后运行：

```powershell
npm install
```

依赖安装完成后，启动开发服务器：

```powershell
npm run dev
```

终端会显示类似 `http://localhost:5173/` 的地址。按住 `Ctrl` 并点击该地址，或将它复制到浏览器打开。结束服务器时回到终端，按 `Ctrl+C`。

## 数据说明

单词和学习记录保存在当前浏览器的 IndexedDB 中。清理浏览器网站数据可能导致数据丢失，请定期在设置页导出完整备份。

单词库页面已经接入数据层。数据库名称、表结构、字段和索引见 `DATA_MODEL.md`。

测试中的 IndexedDB 由 `fake-indexeddb` 在 Vitest 环境提供，并使用独立测试数据库；不会读取或修改你在浏览器中的真实词库。

## 使用单词库

1. 打开应用后进入“单词库”。
2. 点击“添加单词”，填写英文单词和完整中文释义。
3. 相同标准化单词已存在时：
   - 释义相同：保留原记录，不重复添加。
   - 释义不同：对话框显示新旧释义；未选择更新时默认保留原释义。
4. 每张单词卡片可“查看详情”“编辑”或“删除”。
5. 删除会同时清理该词的分组关联、复习状态和学习历史，确认后才执行。
6. 使用“搜索”框按英文显示形式或中文释义即时筛选；清空搜索框恢复完整列表。

英文单词最多 100 个字符，中文释义最多 2000 个字符。分组名称最多 50 个字符且不能为空。

## 导入 Excel / CSV

1. 进入“单词库”，点击“导入单词”。
2. 选择 `.xlsx`、`.xls` 或 `.csv` 文件。
3. Excel 用户选择一个或多个工作表；CSV 会直接进入列映射。
4. 逐个工作表确认英文单词列和中文释义列。
5. 检查预览、来源工作表和原始行号，处理已有释义或文件内多重释义冲突。
6. 查看最终新增、更新、跳过和无效数量，再确认导入。
7. 导入完成后返回单词库，刷新页面数据仍来自 IndexedDB。

CSV 支持 UTF-8 和带 BOM 的 UTF-16 编码；GBK/GB18030 等其他编码会明确报错，不会把乱码作为释义写入。

导入最后一步使用单个 IndexedDB 事务。任何写入失败都会整体回滚，更新释义不会改变单词 ID、分组关联、复习状态或学习历史。

## 学习单词

1. 进入顶部导航的“学习”。
2. 选择“英译中”或“中译英”。
3. 先自行回忆，点击“显示答案”后再选择“忘记了”“模糊”或“记住了”。
4. 只有反馈保存成功才会进入下一题；保存失败可重试，不会产生重复记录。
5. 一轮结束后可检查下一轮。忘记的单词约 10 分钟后到期，届时可重新进入后续轮次。

基础学习页面使用全局学习来源，并会把成功反馈计入当天任务和统计。

## 每日任务与统计

1. 在“设置”中填写 0–999 的每日新词目标并保存。
2. “今日”页面显示基础目标、以前结转、名义任务、有效任务、新词完成、复习完成和剩余新词。
3. 修改目标会立即重新计算今天，但不会减少已经完成的数量。
4. 词库不足时有效任务只按实际可安排的新词计算；之后导入新词会动态增加。
5. “统计”页面可切换近 7 天、近 30 天和全部历史，查看全局新词/复习趋势、记忆反馈比例、薄弱词变化和独立分组统计。

全局趋势遵守同日同词去重，分组学习不进入全局任务；记忆反馈和薄弱词分析来自完整学习历史。切换时间范围只筛选页面已加载的数据，不会重复读取整个 IndexedDB。

首次使用尚未设置目标时，新词任务为 0，但到期复习仍可学习。

## 使用分组

1. 在“分组”页面创建分组，也可以重命名或删除分组。
2. 进入分组后点击“添加单词”，可从总词库批量选择成员。
3. 分组词汇页会同时显示组内多个单词；点击单词可独立展开完整中文释义。
4. 展开释义只是查看，不改变复习状态、学习历史或每日任务。
5. 展开后可选择三档反馈。分组反馈会更新共享复习状态，但不会增加全局每日任务完成量。
6. 从分组移除单词或删除分组不会删除原单词和学习进度。

## 使用单词检验

1. 顶部导航进入“检验”。
2. 选择“全部词库”或某个分组。
3. 默认只显示英文；点击单词查看完整中文释义，再次点击收起。
4. 可以同时展开多个单词，也可以搜索英文或中文释义并调整排序。
5. 检验只做本地浏览，不记录认识结果，不调用复习算法，也不写入学习历史或每日任务。

分组学习页面仍保留原有反馈功能，与单词检验相互独立。

## 使用薄弱词强化

1. 顶部导航进入“薄弱”。
2. 列表使用全部学习历史累计薄弱分：忘记 +3、模糊 +1、记住不加不减。
3. 排序依次比较薄弱分、连续忘记次数、EF、上次学习时间和英文显示形式；不按是否到期额外筛选。
4. 点击单词查看完整释义，再提交“忘记了”“模糊”或“记住了”。
5. 反馈会更新该词唯一的共享复习状态和学习历史，并计入今日全局复习完成量；同一天同一单词只计一次。
6. 分组反馈仍只计入分组统计，但与全局和薄弱反馈共享同一份复习状态。

“统计”页面同时显示当前薄弱词数量。

## 完整备份与恢复

1. 在“设置”页点击“导出完整备份”，浏览器会下载一个 JSON 文件。
2. 备份包含单词、分组、分组关联、复习状态、学习历史、每日任务和应用设置。
3. 恢复时选择备份文件；应用会先校验格式、版本、字段、主键、时间日期和关联关系。
4. 校验成功后页面显示待恢复摘要，并提示先导出当前数据。
5. 勾选覆盖确认并点击“确认完整覆盖恢复”后，应用在一个事务中替换全部数据。
6. 恢复成功会刷新页面；恢复失败会显示错误，原有数据保持不变。

首期只支持完整覆盖，不支持合并或选择性恢复。备份文件上限为 25 MiB；未来版本或不兼容版本会被拒绝。

## 质量与已知限制

- 自动化测试包含 24 个测试文件、225 项用例；同时执行 TypeScript、ESLint 和生产构建。
- 已在独立临时 Edge 配置中完成桌面、390px 手机、CSV/Excel 导入、学习、分组、检验、薄弱、统计和备份恢复验收。
- 压力检查使用约 1,400 个单词、6,000 条学习历史和 365 天统计图；普通页面加载和范围切换保持可用。
- 当前只支持备份格式版本 1，旧版备份迁移策略尚未确定。
- Excel/CSV 在主线程解析，尚未设置固定导入文件大小上限；超大文件可能使页面短暂等待。
- 连续多日未打开应用时，是否补算每个未打开日期的每日目标仍待业务确认。
